Mac **0.11.0 → 0.12.0**.

## The Mac app is signed and notarized

Until now the Mac app was unsigned, so on any other Mac the first launch needed right-click → Open. It is now signed with a Developer ID certificate and notarized by Apple, so it **opens like any other app** — no Gatekeeper workaround.

## Finder ▸ Share ▸ "Send to Phone" works

Right-click a file in Finder, choose **Share ▸ Send to Phone**, and it goes to the phone's `Downloads/Link to Mac`. The menu entry has been in the app for a while, but macOS only runs a sharing extension from a properly signed app, so it did nothing before. Dragging onto the window or the menu-bar icon still works too.

## Smaller things

- **The Back button now sits next to the window buttons** when you open Settings, Clipboard history or About, with the screen's name beside it. **⌘[** goes back as well.

## Known limitations

- **After updating from 0.11.0, macOS may ask again** for Bluetooth (used by "lock when the phone leaves") and for notification permission: a permission is tied to how the app is signed, and the signature changed. Allow them once.
- **Dragging from Mail, Photos or Safari's download list** isn't supported (they hand over a promise of a file, not the file). You'll get a notification saying so; drop the file from Finder.
- Everything listed as a limitation in 0.11.0 still applies (1 GB per file, folders limited to 1,000 files, resume needs the receiver to still hold the partial file).

## Install

**Android:** sideload `linktomac-preview-0.12.0.apk`.
**macOS:** existing installs update themselves via Sparkle; new installs open `LinkToMac-0.12.0.dmg` and drag the app to Applications.
