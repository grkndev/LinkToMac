Both apps update this time: Android **0.10.0 → 0.11.0**, Mac **0.10.0 → 0.11.0**. Install both — resume and big files need each side. (An older app on either end keeps working; it just doesn't get the new parts.)

## A Files screen on your phone

The "Received files — Soon" card on Home is now **Files**, and it opens a real screen:

- **Send files** and **Send folder** — pick them in the system picker. A folder arrives on the Mac with its structure intact.
- **What's going out right now**, with its percentage. Tap it to cancel.
- **Everything you've sent and received**, newest first, and it's still there after a restart. Tap a received file to open it; tap a send that failed or was cancelled to **retry** it; **Clear** empties the list (the files themselves stay where they are).

## Files up to 1 GB, and a cut-off transfer picks up where it stopped

- The limit is now **1 GB per file** (it was 64 MB). The Mac used to hold every piece of a file in memory before saving it; it now writes pieces straight to disk, and the phone sends a big file directly instead of copying it into its own storage first — so a 1 GB file doesn't need 1 GB of free space.
- **Resume.** If a transfer is interrupted — you cancelled it, the connection dropped, an app was closed — just send the same file again. The receiving side tells the sender how much it already has, and only the rest goes. There's nothing to configure: re-drop it on the Mac, re-share it on the phone, or tap **Retry** in Files. The receiver keeps a half-received file for 10 minutes.

## Folders, both ways

Dropping a folder on the Mac already worked; the Mac now also **receives** folders from the phone and recreates the tree under `Downloads/Link to Mac`.

## Smaller things

- **Cancel from the notification.** The progress notification for a file you're sending now has a **Cancel** button.
- **The "Grant SMS Send Access" button explains itself.** On an app installed outside the Play Store, Android blocks SMS access until you allow it, and then refuses to ask again — the button used to do nothing. It now tells you the steps (⋮ → *Allow restricted settings*, then *Permissions → SMS → Allow*) and opens the right screen.
- **"Send copies" and "Send images" are gone from the phone's Settings.** The phone always sends what it copies; the Mac still has its own switches if you want a one-way flow.
- **One banner for a burst of files** on the Mac ("3 files"), as on the phone, instead of one per file.
- **A development build and the release build installed side by side** no longer mirror each other's notifications to the Mac.

## Known limitations

- **Finder ▸ Share ▸ "Send to Phone" still does not work** — macOS refuses to run an app extension that isn't signed with an Apple Developer certificate, and this app is deliberately unsigned. Drag and drop instead.
- **Dragging from Mail, Photos or Safari's download list** isn't supported (they hand over a promise of a file, not the file). You'll get a notification saying so; drop the file from Finder.
- **Resume needs the receiver to still be holding the partial file**, so it works across a dropped connection or a cancel, but not if the *receiving* app was quit or restarted in between (it then starts over).
- **Retry in Files only exists for sends you started inside the app.** Files shared from another app's share sheet can't be retried from the list — the permission to read them ends with the share — but sending the same file again still resumes.
- **A folder is limited to 1,000 files**, and the Mac keeps at most 8 levels of nesting (deeper levels are flattened).
- **Sending a very large file makes the Mac app's memory use climb to a few hundred MB** and stay there for a while. It does not grow with the file's size when *receiving*.
- **1 GB per file.** Larger files are skipped, with a message.

## Install

**Android:** sideload `linktomac-preview-0.11.0.apk`.
**macOS:** existing installs update themselves via Sparkle; new installs open `LinkToMac-0.11.0.dmg` (right-click → Open, since the app is unsigned).
